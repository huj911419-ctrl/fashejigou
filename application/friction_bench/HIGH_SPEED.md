# 分级升速验证与控制优化

2026-10-11。适用：M3508/C620、三轮 120°、42 mm 弹丸、去减速箱直驱。

## 本轮已经修改

摩擦轮 speed group 单独启用 `PID_ConditionalIntegration`。以候选 P+I+D 输出和本次实际积分增量判断：将使输出进一步超限的积分不累加，帮助输出退出饱和方向的积分仍允许；积分本身始终在配置限值内。旧 `PID_Integral_Limit` 行为保留给未选用新策略的应用。

这是修正限流时的控制行为，不是已经完成实机最优整定。Kp=2.1、Ki=0.02、Kd=0、限流14000 raw、斜坡1300 RPM/s、最高7500 RPM、遥控上限2000 RPM仍为原配置。只提高最大转速不会自动获得更好的弹速或恢复能力。

参考 [MathWorks 条件积分与抗积分饱和说明](https://www.mathworks.com/help/simulink/slref/anti-windup-control-using-a-pid-controller.html)。本实现只考虑 PID 自身输出上限，不建模电调电压/功率限制，也不推断实际电流已经达到指令。

USB `log 2` 配置头新增：

```text
FRCTRL,policy=speed_pid_conditional_v1,continuous=1,anti_windup=conditional,output=current_raw
```

保留该行及 FRMETA/FRPID 等配置。旧日志没有 FRCTRL 时不能当成同一控制策略。运行采样字段和 schema=1 帧格式不变。

同时修复：关闭的 RTT/USB/VOFA 等来源与非法来源不能借运行请求取得空闲控制权；显式选择和运行请求共用来源可用性判断。停机语义保留。

## 更快的首轮采集

前提：无弹、固定机构，已确认轮子紧固、无擦碰，机械允许试验转速。以下是早期无弹采集序列，不是发射转速推荐；出现故障、不转、明显振动/擦碰、转速持续上不去时结束该次试验，将原始日志交给 AI，不继续升档。

1. 烧录最新 `build/friction_bench/Meta-Embedded-NG-friction_bench.hex`。
2. 串口助手停止已有循环发送，逐条发 `source usb`、`off`、`status`，确认来源与停用。USB 来源下遥控开关不控制轮子。
3. 开始 UTF-8 原始日志保存，逐条发 `log 2`、`log period 20`、`stream on`，保留开头5秒停机记录。
4. 每100 ms重复发送当前一条 set 命令。先只测试F1，按表顺序更换目标；任何一次更新中断超过250 ms都可能触发命令超时，不能当成PID问题。如果超时，结束采集并明确停机，不靠重复RUN解除锁定。

| 阶段 | F1命令 | 时长，从该阶段命令开始计 |
| --- | --- | --- |
| 检查方向与明显机械异常 | `set 1 500 0 0` | 5秒 |
| 观察加速与稳态 | `set 1 1000 0 0` | 10秒 |
| 继续提高工作点 | `set 1 1500 0 0` | 10秒 |
| 本轮上端观察 | `set 1 2000 0 0` | 20秒 |

5. 关闭循环发送，单独发 `off`，保存至少5秒停机过程；确认实际停用，轮子滑行至停转。随后发 `status`、`events`、`stream off`，结束文件保存。
6. 交付 `F1_500-2000rpm.txt`、物理轮位置、轮径、供电信息和异常描述。AI检查完整性、各档误差/饱和/温升，指定下一轮具体命令和参数。

这是一轮约55秒的筛查数据，替代只在500 RPM长时间观察的首轮安排。它不替代最终每工况30秒以上稳态、重复性、热态和出弹验收。先分析F1，再给F2/F3及三轮同时的序列。

若串口助手不能可靠地更换周期命令，每个档位单独完成“off→周期set→停止周期→off”，保持日志连续即可。不要为了连续扫速关闭250 ms命令租约。自动试验执行器尚未实现。

2000 RPM是本轮观察点，不是最终目标。确认轮径、机械允许值和本轮日志后，再由AI指定更高档位与时长。7500 RPM是软件输入上限，不是已经通过实机验收的工作点。

## 高速时下一步优化的依据

- **参考斜坡与掉速恢复分开**：1300 RPM/s控制参考值变化；参考已经稳定时，过弹导致的实际掉速不会让参考重新爬坡，恢复直接由速度环和动力余量决定。0→5000 RPM仅参考爬升就约3.85秒，增加斜坡只在目标变化阶段直接生效。
- **整定接近最终工作点**：500 RPM不能代表高速包胶阻力、振动或过弹负载。逐轮拟合后比较PI候选；如需要再评估电流前馈。暂不引入未经数据证明有益的D项或复杂控制器。
- **高速记录优先于漂亮波形**：当前20 ms日志、经过滤波的反馈可能漏掉掉速谷值。后续增加短时高频缓冲、原始反馈时刻和出弹事件，低优先级导出，不在1 ms控制任务打印。
- **READY需与射频匹配**：当前一旦退出就绪并重新满足条件，需重新连续稳定200 ms。这个时间不应凭感觉缩短，应由实测恢复、弹速波动和供弹时序确定；就绪也不等于已经允许发射。
- **轮面速度与弹速分开**：直驱近似轮面速度 `pi*直径(m)*RPM/60`。实际弹速还受轮形、压缩、滑移和受载掉速影响，需要独立测速。
