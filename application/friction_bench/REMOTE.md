# 六档遥控摩擦轮

仅控制当前三只 DJI 摩擦轮。遥控只生成目标，原电机任务执行斜坡、逐轮 PID 和电机保护。没有接入云台、供弹或自动发射。摇杆不参与摩擦轮控制，UART10 VOFA 通道保持不变。

## 接线与档位

沿用已跑通的 DT7/DR16：Board02 P6 DBUS → 板载反相电路 → PD2/UART5，100000 baud、8E1（HAL 9B 含校验位）。

默认 DBUS 位置值为上=1、中=3、下=2；S1/S2 名称按解码字段，请通过 USB `status` 的“遥控档位”核对物理开关，不根据左右位置猜测。`status raw` 可查 `[remote_input]` 原始字段。首次确认位置时保持电机动力电源关闭。

| S1 | S2下（2） | S2中（3） | S2上（1） |
| --- | --- | --- | --- |
| 上：停止（1） | 停止 | 停止 | 停止 |
| 中：低速组（3） | 1档：1000 RPM | 2档：2000 RPM | 3档：3000 RPM |
| 下：高速组（2） | 4档：5000 RPM | 5档：6000 RPM | 6档：7000 RPM |

单位均为电机转子 RPM，不是弹速。6000 为当前手动单发测试基准；六档不能当作已标定的竞赛弹速档位。

## 烧录后直接操作

1. 烧录 `build/friction_bench/Meta-Embedded-NG-friction_bench.hex`，接上接收器并打开遥控器。
2. S1 放在停止位置，保持约 0.2 秒，确认遥控 ONLINE、S1=1。
3. 先将 S2 放在一档位置（值2），再将 S1 切至低速组（值3），三轮升至1000 RPM。
4. S2 切换组内档位，S1 切换低速/高速组；三轮使用同一档位目标，按当前2000 RPM/s斜坡升降速。
5. S1 拨停止立即停止驱动、滑行，不走降速斜坡。

上电默认 REMOTE，不用电脑循环发送 `set`。上电时S1已经在运行组，不会自动启动；必须先接收到新鲜的S1停止帧。解锁不要求摇杆回中。0.2秒是操作建议，代码没有新增0.2秒硬性等待。

换档只更新目标，不重新初始化PID、不改变PID参数、不切换控制来源；实际转速仍须看反馈。当前就绪规则和电机保护保持原值。

## 停机与来源切换

遥控断线超过100ms、无效帧、UART错误/队列溢出请求停机。重连保持运行档不会自动恢复，S1必须先拨停止再选运行组。电机故障恢复同样要求停止解锁，原因未消失时不能恢复。

USB `off` 随时可停机，之后遥控也需要重新拨S1停止。USB仍能查询、记录和停机调参，不会借诊断或调参刷新运行租约。

改用电脑控制（逐条发送并等待停机处理）：

```text
source usb
off
```

再按原规则每100ms循环发送，例如 `set 7 6000 6000 6000`。USB来源下遥控不会接管或改变目标；`set`语法不变。USB轮询不能替代遥控帧。

切回遥控发一次 `source remote`，然后S1先停止再选运行组。来源切换排队停机，收到错误时不能当作已切换。同来源重复source不解锁、不续期。重启重新默认遥控；关闭遥控编译开关时，USB开启则默认USB，并保留原来直接首条set启动行为。

## 日志与VOFA

- `status` / `log 1`：简报显示控制来源、停机原因和三轮目标/实际转速；`log 1` 默认每5秒输出。
- `status detail`：中文显示开关、组、档、选择转速、生成目标及解锁要求。
- `status raw`：`[remote_input]`显示开关；`[remote_gear]`显示组、档、选择转速、上一次换档和原始接收时间；`[remote_control]`显示是否等待停止、生成目标和提交结果。
- `log 2`：`FRGEARCFG`列出六档配置；`FRGEAR`记录当前选择、目标、上次档位、换档时间与计数。原`FRRC`列顺序保留，摇杆字段仅供观察。
- 换档历史只保留最新一次转换和累计数；日志覆盖连续记录时可重建多次变化。USB抽样若遗漏短暂档位，计数可以发现缺口，但不能还原所有瞬间。
- 档位和生成目标不等于电机已运行；结合`FM`来源、`FS`实际使能/故障/就绪、各轮`FW`和原始时间判断。
- VOFA实际转速仍为14/24/34，最终目标12/22/32，斜坡给定13/23/33，误差15/25/35。

## 移植与配置

映射集中在 `friction_remote_config.h`：STOP/低/高的S1值、三个S2值、2×3 RPM表、100ms超时。核心校验开关值互异、档位转速有限且正数、不超过上限；组合层要求遥控上限不超过摩擦轮上限，且超时短于运行租约。

`BENCH_ENABLE_FRICTION_REMOTE=0`关闭接收器资源；只开某轮时遥控仅启动该轮，F1/F2/F3编号固定；全部关闭不会启动UART5。与云台遥控开关独立。

```text
UART5字节队列 → dbus_input协议 → robot_cmd/friction_remote档位与解锁
            → friction_remote_bench来源与邮箱 → FrictionTask斜坡/PID/CAN
```

实机首次验证：上电保持运行档不启动、1000档三轮运行、摇杆不改转速、换档斜坡、S1停止、断线/重连解锁、USB急停/来源切换。主机测试和编译通过不代表这些遥控实机项目已经通过。
