# 42 mm 三摩擦轮实机验证与数据调参计划

更新：2026-10-10。状态：验证设计，尚未完成本计划的实机试验。

2026-10-11 补充：[分级升速步骤与控制优化](HIGH_SPEED.md)。新增摩擦轮条件积分策略及日志标识；首轮允许采用500→1000→1500→2000 RPM短时分级采集。自动试验执行器、高速采样和测速关联仍待实现。

## 1. 已确认条件与目标

用户确认：42 mm RoboMaster 竞赛弹丸，三个摩擦轮相隔 120°、中心进弹，电机没有减速箱。当前工程使用 M3508/C620 速度控制，直驱时转子 RPM 就是轮子 RPM。

目标是指定工况下弹速、散布、恢复时间和可靠性可重复地满足要求。空转波形漂亮只是其中一项。不能在没有实测数据时保证绝对最优，也不能用电机转速替代弹速测量。

分工：用户负责固定机构、测量尺寸、运行指定试验并提供原始日志；AI 负责数据检查、模型拟合、参数选择、对比报告、下一轮具体命令或配置。用户不需要自行猜 Kp/Ki/Kd。机械改装和现场操作仍需人执行。

仍需记录：三个轮的外径、轮形、包胶材质/硬度、安装支撑方式、供弹机构、工作电压；比赛类别/赛季、目标距离、目标尺寸和射频。未知项明确标 UNKNOWN，不能代填成典型值。42 mm 本身不能唯一确定比赛允许弹速。

## 2. 现有代码能做什么

核对入口：`friction_config.h`、`USB_LOG.md`、`REMOTE.md`、`module/motor/dji_speed_group/`、`module/motor/DJImotor/`、`module/algorithm/controller.c`。

| 项目 | 当前行为 | 验证含义 |
| --- | --- | --- |
| 三轮速度环 | Kp=2.1、Ki=0.02、Kd=0，逐轮限流 14000 raw | 初始配置，不是已验收参数；raw 不是电源输入安培 |
| 单位 | PID 误差是 deg/s，等于 RPM 误差乘 6；积分时间为秒 | 不能直接抄使用 RPM、rad/s 或离散积分的其他工程增益 |
| 输出 | C620 电流指令 | 不直接套电压驱动的前馈系数 |
| 控制与反馈 | 控制标称 1 ms；速度和电流分别以 0.85、0.9 的新样本权重滤波 | 必须记录真实 CAN 样本时刻；控制调用不等于新反馈到达 |
| USB 运行日志 | 最快目标周期 20 ms；积压会跳帧；有完整性/故障/参数修订信息 | 可做稳态和较慢响应分析，不能证明毫秒级掉速峰值 |
| READY | 进入 max(10 RPM, 2%)、退出 max(20 RPM, 4%)、保持 200 ms | 只是当前速度就绪条件，不是供弹许可或比赛验收结论 |
| 控制来源 | 默认 REMOTE；USB 与遥控互斥 | 精确重复试验优先使用固定 USB 目标；摇杆主要做功能检查 |
| 电脑工具 | `tools/usb_console.py` 只读日志工具 | 目前没有一键执行试验、拟合、写入、复测的自动调参器 |

最高 7500 RPM、70°C 保护和遥控 2000 RPM 上限都是现有配置边界，不代表机构已经适合在这些边界运行。机械额定转速、电源能力和材料温度限制需单独确认。

`off` 是零电流滑行停机，轮子不会瞬间停止。USB 来源下遥控开关不会控制轮子，不能把它当成 USB 试验的急停。停止周期发送后发 `off`，确认实际停用；现场保留可直接切断动力的手段。

## 3. 没有测速仪时如何测弹速

### 3.1 首选：借用兼容的官方测速模块；备选：双光电门

双光电门是在出弹后固定两道非接触检测平面，用已知间距 L 和同方向对应遮挡沿的时差计算：

`v_average = L / (t2 - t1)`。

这是两平面间平均速度，应记录检测位置，不能不加说明称为精确枪口瞬时速度。两道检测平面必须在弹丸脱离摩擦轮之后、安装架不能擦碰弹丸。优先使用相同响应特性的对射传感器；具体器件要核对响应时间、光路覆盖、输出电平和抗环境光能力，普通避障模块不自动满足要求。

示例仅解释量级：L=0.20 m、经过时间 12.5 ms 时平均速度为 16 m/s，不是本项目推荐弹速。间距误差 1 mm 就贡献约 0.5% 相对误差；1 us 计时量化在该例只约 0.008%，但传感器延迟差和安装误差仍可能占主导。因此不能看到微秒时间戳就宣称测速精度达到微秒对应比例。

板端使用同一硬件定时器的输入捕获记录两通道边沿，处理计数回绕、重复沿、缺失第二门、反向经过和超时。引脚、定时器待核对板卡占用后分配，不挤占现有 CAN、遥控和 VOFA。USB 接收时间、毫秒任务轮询不能用作测速时间基准。

球体横向路径变化会改变单束光被遮挡的几何时刻，两门光束相对路径应一致，必要时用覆盖通道的光幕。不能只用单门遮挡时间和 42 mm 直径相除：光束可能截到球体弦长，未必穿过球心。

验收测速链：精确测量两检测平面间距；用已知脉冲检查计时；检查环境光、偏心通过、双弹、漏门和错序；改变已知间距做一致性检查。脉冲测试不覆盖光学误差，最终尽量与借来的已知精度测速仪/官方测速模块交叉验证。未经交叉验证的自制装置不能保证与裁判系统读数一致。

未来每发输出：shot_id、两门原始时间戳、间距/校准版本、有效标志、无效原因、平均速度、对应运行编号和参数修订。出弹检测时间晚于轮子接触时间，不能直接把它当作负载开始时刻。

### 3.2 手机慢动作：先做粗测和偏弹观察

固定手机从侧面拍摄，标尺放在弹丸运动平面，镜头尽量垂直于该平面；用原始拍摄帧率和视频时间戳计算，避免把插帧后的慢放帧率当作拍摄帧率。光照和快门应足以辨认球心，使用多帧位置拟合。

例如真实 240 fps、16 m/s 时每帧移动约 66.7 mm；跨 0.5 m 仅约 7.5 帧，一帧时间误差就很大。它适合发现明显速度差、擦碰和出射方向变化；不能默认拿来验收 1% 弹速稳定度。拍摄距离不同也会引入空气阻力造成的平均速度差异。

## 4. 分阶段试验，前一阶段有证据再进入下一阶段

### A. 建立机械与配置基线

断电时给物理轮标 F1/F2/F3，记录其 CAN ID、位置、旋转方向、外径、轮形、材质和装配版本。照片至少包括正面、侧面、三个轴承/电机连接位置及进弹通道。低速点动时确认每个接触点的切向运动都朝出弹方向；相同 CAN 正号不保证装配后的方向正确。

用卡尺测外径和安装距离；优先借百分表测轴/轮毂定位面及包胶外缘的径向跳动、端面跳动，并记录测量基准。软包胶要固定测头压力，区分表面粗糙度与偏心。不凭一个通用毫米数判定所有轮形合格，也不照抄其他队伍的压缩量。无百分表只能先筛查明显偏摆，不能给出精密装配合格结论。

检查紧固、防松、轴承间隙、轮子擦边、轮毂打滑、包胶脱胶以及供弹轴线。名义 120° 不保证三点实际接触对称；接触平面、轮径和支撑挠度同样重要。对称设计的三轮压缩应对称，但具体压缩定义依实际 CAD/轮形建立。

断电受控推过弹丸检查路径和不均匀卡点；运行时不伸手向旋转轮口送弹，带载试验用固定、可重复的供弹机构和拦截设施。比较空载与过弹时支架位移，特别检查“空转减振很好、受力却外张”的软支撑。

### B. 单轮无弹基线

F1、F2、F3 分别执行相同的低速、斜坡、恒速、停机序列。首轮先保留现有增益；试验转速和限流在轮径、机械允许值及配置头明确后由 AI 给出。固定每轮测试时长；稳态段至少 30 s，每个关键工况重复 3 次。不能用任意手推摇杆曲线比较两个 PID 的优劣。

记录目标/参考/反馈、输出/电流、饱和、温度、反馈年龄、实际时间间隔、故障、参数版本。比较相同转速和同一电源条件下的噪声、温升、空载电流、滑行减速。疑似机械异常时，按可拆装条件比较裸电机与带轮结果。

### C. 数据辨识和逐轮调参

AI 先验证日志质量，再以有界、可重复的小幅目标变化采集动态响应，拟合带延迟/滤波的电流指令到速度模型。闭环日志存在输入输出相关性，不能直接把普通最小二乘拟合结果当成真实对象；需设计足够激励、检查残差，并用未参与拟合的另一组试验验证预测。

先调 PI，D 默认保持 0。根据实测响应、噪声、饱和和控制延迟选择候选增益；没有足够数据时明确要求下一项试验，不编造精确参数。现有限流若导致加速度受限，增大 Kp 不能解决动力不足。

候选需与基线比较跟踪误差、超调、恢复时间、电流峰值/持续饱和和温升，不能只追求最快。若 PI 在多个工况受限，再评估由实测得到的电流前馈；不能把 WPILib 的电压前馈常数直接用于 C620 电流指令。三轮允许不同控制器参数，但差异过大先排查机械/反馈/电调问题。

参数只在停用状态切换；核对实际应用修订和 FW/FRPID 中的值，QUEUED 不算应用成功。保留上一个已验证版本，劣化立即回退。当前 RAM 参数掉电会恢复，不把运行时修改称为已永久保存。

### D. 三轮同时无弹

重复同一序列，比较与各轮单独运行时的差异。单轮正常、同时异常，重点查供电压降、接插件、共振和控制调度。电机电流反馈不能替代电源电压或输入电流测量；万用表能看慢变化，快速压降需有足够采样率的电压记录。

直驱圆柱轮近似轮面速度为 `u = pi * D * RPM / 60`，D 单位 m。轮径不同，即使 RPM 相同轮面速度也不同。基线按设计要求比较接触表面速度；有意赋予弹丸旋转时则按设计速度比例评价，不能强制所有工况三轮等 RPM。

### E. 固定发射架、低射频单发

先固定云台角度/发射架，排除云台运动误差。确认机械与空载阶段通过后，每个工况先采集至少 30 发作筛查，记录所有失败、漏测和卡弹。候选方案最终每个关键工况至少 100 发并分批重复；样本数是起点，不是可靠性保证，置信区间仍不够窄时增加样本。

每发关联三轮出弹前速度、最低速度、掉速开始/幅度、恢复时间、输出饱和、实测弹速、落点、供弹动作时间和弹丸批次。掉速不对称是机械/供弹线索，也可能来自惯量、增益或反馈延迟差异，不能仅凭三条曲线宣判机械装歪。

先固定控制器，再比较机械参数；不要同一组同时换轮材质、压缩量、转速和 PID。弹速与散布共同作为结果，平均弹速相同不代表散布相同。换压缩量后通常需要重新标定 RPM—弹速关系，由 AI 安排测点，用户按指定尺寸调整。

### F. 射频、热态与可重复性

供弹机构确定后，逐级验证计划射频。下一发必须满足三轮恢复、供弹状态、有效命令及相应比赛约束；不能只凭 READY 置位就允许供弹。实测恢复时间加供弹时序抖动和裕量应小于可用发射间隔，否则降低射频或改进机构/动力。

复测冷机、预热后、预期电压范围两端、不同合格弹丸批次及拆装后的性能。工况顺序交叉安排，避免把温升误当参数改进。电机内温度不是包胶表面温度；需非接触测温或停机后的重复测量方法，并记录测量位置/延迟。

耐久按真实比赛工作周期安排，检查螺丝松动、轮面偏磨、脱胶、轴承间隙、供弹失败和热漂移。最终保留独立于调参数据的验收数据。

## 5. 初始验收目标及如何判定

以下为本项目建议的工程起点，不是 RoboMaster 官方标准，也不是所有轮径/射频通用指标。获取第一批数据后，结合目标和测量能力冻结正式数值，不能为了让某次数据通过而事后放宽。

| 项目 | 初始目标/判定方法 |
| --- | --- |
| 数据有效 | 配置头、单位、参数修订和采样帧可匹配；缺帧/旧反馈/无效测速明确计数；受影响指标标为证据不足 |
| 稳态转速 | 斜坡结束后 30 s，平均误差绝对值 ≤ max(10 RPM, 目标的 1%)；至少 95% 有效样本误差 ≤ max(10 RPM, 目标的 2%)；无持续振荡 |
| 超调 | 非零目标变化后超出最终目标不超过该目标的 5%；低速另设绝对容差；需足够采样率才能宣称真实峰值通过 |
| 输出余量 | 稳态无持续限流；瞬态饱和时长和温升在允许范围；数值阈值待电源和机构能力确定 |
| 弹速一致性 | 初期争取 CV=样本标准差/平均弹速 ≤2%，稳定后评估 ≤1%；报告样本数、均值、标准差、极差及测量不确定度 |
| 弹速边界 | 按实际赛季、赛事和英雄配置查官方规则，给测量误差与波动留裕量；不复制旧赛季 15.8 m/s 设置 |
| 恢复 | 从有明确定义的事件时刻，到三轮重新进入并持续保持目标误差带；与实际射频所给时间预算比较，不预设通用 100 ms |
| 散布 | 在固定距离/俯仰下记录落点偏置、覆盖 95% 样本的散布范围、目标区域命中比例和置信区间；目标尺寸/距离确认后冻结门槛 |
| 热态/重测 | 冷热、电压边界及拆装后仍满足同一套关键指标，无新增卡弹、松动、异常磨损 |

零次失败不能等同于故障概率为零；样本少时明确结论范围。日志无故障不证明机械、弹速或散布通过。

## 6. 怎样区分机械问题和控制问题

| 现象 | 优先排查 | 需要的交叉证据 |
| --- | --- | --- |
| 单轮空载电流/温升明显较高 | 擦边、轴承预紧、不同惯量、驱动异常或环路振荡 | 断电手转、裸电机对照、定位面跳动、同条件日志 |
| 振动随轮转频移动 | 偏心、不平衡、支撑共振等 | 百分表、转速扫描、振动记录；转频=RPM/60，20 ms 日志对高频会混叠 |
| 三轮一起才掉速/振动 | 供电能力、连接电阻、结构共振、调度 | 同时记录电压，比较单轮与三轮、查看 FT/FRCAN |
| 速度平稳但弹速/散布不好 | 压缩、打滑、供弹定心、包胶状态、结构受力偏移 | 光电测速、落点、过弹录像、压缩和轮温记录 |
| 同一轮总是先掉速或掉速更大 | 接触先后不一致，也可能惯量/滤波/增益不同 | 高频原始反馈时刻、机械尺寸、视频及空载辨识结果 |
| 空转很好、过弹时轮架外张 | 支撑刚度/安装松动不足 | 固定视角录像/位移测量；不能只加软减振件 |
| 热机后弹速漂移 | 包胶温度变化、磨损、电源变化或摩擦变化 | 同配置冷/热对照；电机温度和轮温分开记录 |

结论采用“发现—可能原因—验证动作—结果”的形式，不用一条日志猜唯一原因。

## 7. 自动化实现顺序（尚未实现）

1. **离线日志分析器**：解析现有原始 USB 文本和配置头，按会话/参数/命令分段，检测缺帧，输出每轮指标、波形和证据不足项。保留原文、报告、参数版本，支持用户直接提供文本文件。
2. **有界试验执行器**：电脑单独拥有串口，执行固定时长的单轮/三轮试验并按租约发送命令，同时记录回复；开始前核对固件/来源/限值。超时、断线、异常反馈、意外来源/参数变化即停止，不无限自动重试启动。
3. **板端短时高速记录**：预分配环形缓冲，记录原始和滤波反馈、CAN 到达时间、PID 输出/限流、控制时刻；围绕事件保留前后窗口，低优先级导出。先测实际反馈率、缓存与带宽预算，重复旧反馈不算新样本；禁止在 1 ms 控制任务 printf。
4. **可移植双门测速核心**：`module/` 处理两门配对/时间差/无效原因，`bsp/` 接硬件捕获，`application/` 关联 shot_id 与试验；硬件管脚后绑定，可独立关闭，不依赖云台业务。
5. **拟合、候选参数与复测**：AI 根据模型及实测比较给出逐轮 PI、限流建议、斜坡、READY 及试验目标。应用需停用并核对实际版本；候选不过则回退，不进行无界增益搜索。机械额定边界不因拟合结果自动放宽。
6. **出弹验收报告**：结合测速和落点记录，对冷/热、电压/射频工况报告通过、失败、证据不足，生成可复现参数与机构版本清单。

真正的一键调参要把上述链路实现并测试后才能宣称具备；目前已具备遥控/USB 运行、在线调参和运行日志基础。本次只形成规划，不改变控制代码、不烧录、不执行电机命令。

## 8. 下一次交接的最小材料

先无弹，机构固定。停止串口助手的周期 `set`，通过原串口助手发送 `off` 并确认停用；保持遥控开关在非启动位置、摇杆回中。

打开 UTF-8 原始接收保存，依次发送下列观察命令，保存约 5 秒。这一段不启动电机：

```text
log 2
log period 20
stream on
status
```

随后 `stream off` 结束采集。提供完整配置头与连续帧，不只给截图或统计摘要。`tools/usb_console.py` 可以做只读采集，但不能用它发送 `off` 或运行命令，也不能与串口助手同时占用同一 COM 口。

同时提供三个轮的外径、装配正/侧面照片、已知材质和供电信息。AI 据此给出第一轮单轮试验的精确目标、时长、限流和日志检查点；第一轮控制调参无需等测速器做好，但最终弹速与散布验收需要独立测量。

## 9. 参考与适用边界

- [华南农业大学 Taurus：RM2025 英雄发射器设计及调试开源](https://bbs.robomaster.com/article/813002?source=4)，附件《华农摩擦轮调试指南》已核对第 6–7、10–14 页。借鉴控制变量、量化弹速/散布、观察轮速扰动和支撑刚度的思路；其五摩擦轮两级机构不同于本项目，压缩量、转速与效果不照搬。
- [rm-controls 发射控制源码 standard.cpp](https://github.com/rm-controls/rm_controllers/blob/master/rm_shooter_controllers/src/standard.cpp)：借鉴各轮速度条件参与供弹判断，以及运行状态与卡弹处理分开。上游是可参考实现，不代表其默认参数、所有保护逻辑适合本项目。
- [WPILib 系统辨识](https://docs.wpilib.org/en/stable/docs/software/advanced-controls/system-identification/introduction.html)：借鉴试验采集、模型拟合、验证流程；其示例输入为电压，本项目为电流指令，不直接移植系数。
- [Vernier 光电门原理](https://www.vernier.com/manuals/vpg-btd)：两门已知距离/经过时间，以及单门测量的几何限制。
- [ST AN4776 定时器应用说明](https://www.st.com/resource/en/application_note/an4776-how-to-use-generalpurpose-timer-peripheral-on-stm32-mcus-stmicroelectronics.pdf)：硬件输入捕获的测时方法；具体 H723 时钟和复用配置仍需按本板确认。
- [RoboMaster 官方规则资料中心](https://bbs.robomaster.com/wiki/20204847/809871?source=7)：比赛类别与赛季确认后核对适用版本。本计划未把历史资料的弹速数值当作当前规则。
