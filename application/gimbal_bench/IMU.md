# 板载 BMI088：采集、校准和姿态反馈

用户已确认控制板随云台一起转动。本功能接入独立 `gimbal_bench`，保留现有 J4310 手动速度控制。
当前提供姿态测量和有效性判断，尚未把姿态接入电机角度闭环。

## 分层与资源归属

```text
bsp/imu_port                  H723 SPI2、片选、HAL 超时及错误
       ↓
module/bmi088_sensor          初始化、配置回读、数据校验和 SI 单位
       ↓ ImuSample_s
module/attitude               坐标映射、静止零偏、四元数融合、相对角度
       ↓ AttitudeOutput_s
gimbal_bench/gimbal_imu       唯一任务所有者、安装确认、状态快照
       ↓
GimbalImuGetStatus()          诊断/后续角度控制器读取
```

共同样本类型在 `module/imu_sample/imu_sample.h`。纯 C 核心不包含 HAL、FreeRTOS、旧 INS 或 PID，
没有动态内存。原 `module/BMI088`、`module/imu` 和 QuaternionEKF 保留供旧应用使用；
独立云台不同时链接新旧两套 IMU 所有者。

接法来自本项目 CubeMX 配置及 MC02 示例：SPI2，ACC_CS=PC0，GYRO_CS=PC3。
本端口独占 SPI2。初始化只拉高片选并检查 SPI 状态，不重写 CubeMX 配置。
寄存器初始化在任务中按时间推进，每帧最多 10 字节，HAL 超时为 1 ms。
传输期间不关全局中断，成功和失败均释放片选。HAL 超时受 tick 粒度和抢占影响，不等于实测最坏耗时。

## 上电流程

1. 等待上电稳定，选择加速度 SPI 接口，分别软复位，再等待并确认两个芯片 ID。
2. 逐项配置并读回：加速度 ±6 g / 800 Hz；陀螺仪 ±2000°/s / 1000 Hz。
3. 每约 2 ms 轮询一次完整样本。检查加速度 ID、错误和新数据标志，读取加速度、
   陀螺仪 ID/角速度及温度；任何一步失败都不发布部分样本。
4. 最新云台状态未使能时允许静止校准，需要连续 1000 个合格样本，正常约 2 秒。
   转动、窗口内波动或采样间断会清掉进度；校准不会阻塞任务。
5. 用平均加速度初始化 Roll/Pitch，初始 Yaw 定义为 0；减去本次三轴陀螺仪零偏后开始融合。

校准期间必须实际保持控制板静止。低速匀速转动可能被当成零偏，IMU 自身不能完全区分二者；
软件允许校准不等于证明机械静止。没有使用未知的预设零偏来冒充已完成校准。

手册中的陀螺仪 DRDY 是 280～400 µs 短脉冲，2 ms 轮询可能持续错过它。
这里在正常 1 kHz 陀螺输出模式下把软件采样限制在不快于 500 Hz，并使用加速度保持型新数据标志。
两个传感器未硬件同步，没有 FIFO，也不能凭这些检查证明陀螺仪内部没有冻结。
当前不开启 DRDY 引脚输出、不使用 SPI DMA、不启动加热器。温度仅采集和显示；恒温控制、
温漂补偿和加速度多位置标定需后续根据板卡与实测数据实现。

## 解算和坐标约定

采用六轴比例互补滤波：陀螺仪传播四元数，加速度方向提供重力校正；零偏在启动静止窗口单独估计。
没有复用依赖全局状态和 CMSIS 矩阵的旧 EKF。当前选择便于解释和验证，不代表已经证明优于其他算法。

- 四元数为 Hamilton `w,x,y,z`，表示机体系到参考系的旋转，参考系 Z 向上。
- 机体系目标约定为 X 向前、Y 向左、Z 向上，正旋转遵循右手定则。
- 加速度是比力，静止朝上的轴约为 `+9.80665 m/s²`，不是已经去掉重力的运动加速度。
- 角速度为 `rad/s`，角度为 `rad`。三轴角速度属于机体系，任意姿态下不能把 Z 分量直接当成 Euler Yaw 导数。
- 加速度模长偏离重力超过门槛时暂停重力校正，只传播陀螺仪；这不能排除所有线性加速度干扰。
- 每步用四元数增量积分并归一化。Roll/Pitch/Yaw 使用 ZYX Euler 约定，反馈接口同时保留四元数。
- `yaw_rad` 在 ±π 内；`yaw_unwrapped_rad` 是相对多圈偏航。接近俯仰垂直位置或出现大幅歧义跳变时，
  `yaw_continuous` 置假并保持。四元数仍可能有效，但后续不得继续使用连续偏航控制。

BMI088 没有磁力计，重力不能校正绕竖直方向的偏航漂移。Yaw 相对于初始化方向，
不是磁北或永不漂移的绝对航向；世界坐标稳定控制仍需处理漂移和外部参考。

## 配置入口

启停开关集中在 [`bench_features.h`](../bench_features.h)，采样与姿态参数在 `gimbal_imu_config.h`：

| 参数 | 默认值/含义 |
| --- | --- |
| `BENCH_ENABLE_IMU` | 1，开启独立采集任务；设 0 不创建该任务。`GIMBAL_IMU_ENABLED` 仅为兼容别名 |
| `BENCH_ENABLE_ATTITUDE` | 1；设 0 只采原始数据，不校准、不解算。IMU 关闭时此项自动不生效 |
| `GIMBAL_IMU_ON_GIMBAL` | 1，用户确认随云台转动 |
| `GIMBAL_IMU_MOUNTING_CONFIRMED` | 0，等待实物确认轴向 |
| `axis_map` | `{1,2,3}`，暂时按芯片自身 XYZ 输出 |
| `correction_gain_s` | 2，重力校正增益，单位 1/s，尚未实测调优 |
| `stationary_gyro_rad_s` | 每轴 0.05 rad/s，校准幅值门槛 |
| `stationary_gyro_span` | 0.01 rad/s，窗口内每轴极差门槛 |
| `stationary_accel_span` | 0.2 m/s²，窗口内每轴极差门槛 |
| `accel_gate_m_s2` | 1.0 m/s²，模长与重力允许差 |
| `calibration_samples` | 1000 个连续合格样本 |
| `max_step_ms` / `stale_ms` | 10 ms 最大积分间隔 / 20 ms 数据过期 |

`axis_map` 是带符号轴编号。例如 `{2,-1,3}` 表示机体 X=芯片 Y、机体 Y=-芯片 X、机体 Z=芯片 Z。
这只是格式例子，不能直接当作实际安装结论。重复轴、越界编号和左手反射映射均被拒绝。
目前只支持正交轴重排；小角度安装偏差需后续增加经标定的旋转矩阵。

确认安装方向后才能设置 `GIMBAL_IMU_MOUNTING_CONFIRMED=1`。
`attitude.valid` 表示解算已校准且输入/时序有效；`valid_for_control` 还要求安装已确认、
传感器健康、偏航可用且连续。默认后者为假，未确认的芯片坐标不会被标成可直接用于云台控制。

## 任务与故障

Yaw 优先级 idle+3，IMU idle+2，诊断 idle+1。只有 IMU 任务操作 SPI2 和算法实例；
其他任务调用 `GimbalImuGetStatus()` 取短临界区快照。SPI 和姿态计算都不在临界区中执行。
Getter 还按当前时钟检查快照年龄，避免采集任务停住时旧数据一直被当成有效。

- 初始化时限 2 秒；通信错误、ID/配置回读不符、传感器错误、原始数据饱和或 50 ms 无新样本会锁定采集故障。
- 非有限数据、超范围、积分间隔超限或数据过期会撤销姿态有效性。
- 故障后保留最后数值用于诊断，但有效标志为假；不会自动重新校准或突然设置新的 Yaw 零点。
- 当前通过重启重新初始化。通用 `AttitudeInit()` 可供未来的显式校准流程调用；运行时使用必须由唯一所有者
  执行，同时废弃旧角度目标，不能由其他任务直接重置内部状态。
- IMU 故障不改变当前手动速度模式；未来角度/稳定模式必须把有效姿态作为进入和保持条件。

RTT 每约 200 ms 输出 `[imu]`：传感器状态/故障、解算状态/故障、校准计数、有效标志、安装确认、
Roll/Pitch/Yaw 毫弧度和温度。角速度、四元数、连续 Yaw 从快照接口读取。
没有绑定新的调试串口；后续 VOFA 姿态波形可从该快照接入。

## 验证范围

新增 4 项主机测试，编译实际生产源码：

| 测试 | 场景 |
| --- | --- |
| `bmi088_sensor` | 启动/回读、dummy 字节、正负 SI 值和温度、无新数据、ID/IO/配置/饱和故障 |
| `attitude` | 静止校准、24 种右手映射、倾斜/倒置、已知旋转、正反多圈、时钟回绕、机体系旋转、重力校正、奇异位置和故障锁定 |
| `imu_port` | 真实板级适配配 HAL 替身：片选、有限超时、错误返回、输入缓冲区保护 |
| `gimbal_imu` | 真实驱动→算法→快照，校准授权、安装门槛、旧快照失效、SPI 失败传播 |

这不是实板已经采到正确数据。仍需检查芯片 ID/温度/静止三轴、六面方向、转轴正负、采样抖动、
任务栈、震动与温漂；确认后再接角度外环。运行方法见 [tests/README.md](../../tests/README.md)。

## 依据

- [Bosch BMI088 数据手册](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bmi088-ds001.pdf)：寄存器、SPI 格式、量程、温度和 DRDY。
  同时核对了项目内 `module/BMI088/bmi088-datasheet.pdf` 的 Rev 1.8 文本。
- [Bosch 官方 SensorAPI](https://github.com/boschsensortec/BMI08x_SensorAPI)：SPI 选择和接口约定；未引入整套 SDK。
- [AHRS Mahony 文档](https://ahrs.readthedocs.io/en/latest/filters/mahony.html)：四元数与重力误差反馈公式参考。
  本实现采用比例校正和独立静止零偏估计，不含其完整在线积分零偏估计器。
