# 连续角度到角速度的外环

本模块为后续云台角度保持准备，当前**尚未接入 bench 的电机控制链**。
它是普通 C 计算模块，不知道 CAN 编号、电机 ID、FreeRTOS 或 IMU 驱动。

## 输入、计算和输出

```text
目标连续角度 - 实际连续角度
              ↓
        P + 受限的积分
              ↓
       最大角速度限制
              ↓
       角加速度限制
              ↓
     角速度参考，单位 rad/s
```

`YawAngleInit()` 复制参数；每轮由同一控制任务调用 `YawAngleStep()`，从 `output.rate_rad_s` 读取结果。
初次调用没有已知时间间隔，输出从零开始。后续按实际毫秒间隔计算，超过允许间隔或同一毫秒重复 active 调用会锁定时序故障。
`enable=false` 清空积分、输出和运行故障；再次启用必须有新鲜、有效的数据。配置错误需要重新 Init。
故障时输出立即为零，不使用正常加减速限制拖延撤销；函数返回 true 只表示计算处于 TRACKING，**不授权电机使能**。

## 参数与坐标

| 参数 | 单位与用途 |
| --- | --- |
| `kp_s` | 1/s，角度误差转角速度的比例增益，必须为正 |
| `ki_s2` | 1/s²，积分增益；0 关闭积分 |
| `integral_limit_rad_s` | 积分分量的绝对上限，不能超过速度上限 |
| `max_rate_rad_s` | 输出角速度的绝对上限 |
| `acceleration_rad_s2` | 相邻输出的变化速度限制 |
| `max_step_ms` | 允许的活动调用间隔上限，1～100 ms |
| `feedback_timeout_ms`、`command_timeout_ms` | 数据/命令有效期，上限 1000 ms，不小于 max_step_ms |

没有为实机预置所谓最佳参数。测试中的增益只用于可重复的软件测试。
达到速度或加速度限制时，阻止继续推动饱和方向的积分，允许有助于退出饱和的积分变化。
参数在运行中保持不变；需要修改时先由外部撤销使能，再重新初始化。

目标和测量值必须是**同一个坐标系、同一个零点的连续角度**，单位 rad，使用 double 保存。
本模块不会自动把误差折到 ±π。比如目标是 +7 rad，就保留超过一圈的含义；目标 -3.2、实际 +3.2 时误差为 -6.4 rad。
如果应用希望走最短路径，需要在目标管理层选择对应的连续目标，不能把包络角直接送进来。
正速度应能使这个坐标中的测量角度增加；电机方向、减速比、世界/机构坐标关系由组合层确认与转换。

`reference_id` 是组合层提供的角度参考编号。更改零点、重新校准/初始化或重建连续角时需要改变它。
运行中发现编号变化会锁定故障，阻止继续追踪旧坐标中的目标。重新启用前，应在新参考下重新建立目标。
当前 IMU 反馈的安装确认、valid、heading_valid、yaw_continuous 和样本年龄，都必须由组合层一并检查。

## 故障位

| 位值 | 含义 |
| --- | --- |
| 1 | 非法配置 |
| 2 | 非有限输入、数值溢出或缺少输入 |
| 4 | 无效/过期反馈，包括来自未来的不合理时间戳 |
| 8 | 命令过期 |
| 16 | 活动控制周期异常 |
| 32 | 角度参考编号改变 |

时间统一使用同一个 uint32 毫秒时钟，正常回绕可处理。所有 API 由一个任务拥有，不能让 USB 或中断直接改 controller 内部状态。

## 已做的软件验证

`tests/yaw_angle/test_yaw_angle.c` 使用真实模块，检查速度/加速度边界、积分累积与防饱和、多实例、连续多圈角度、时间回绕、异常数据、失联/恢复、命令超时和零点变化。
另用一个人为设定的一阶速度响应模型检查跟踪和扰动恢复；该模型没有由 J4310 实测辨识，不能证明实机稳定性、整定效果或抗扰性能。
接实物时仍需低速核对方向/单位/反馈，再逐步确定增益和限幅。当前工程不会调用本模块使电机进入角度控制。
